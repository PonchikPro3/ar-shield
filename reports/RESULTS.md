# Размещение Sunny Kitty в реальном окружении — 17.10.2026

Сайт: https://ponchikpro3.github.io/ar-shield/WebGL/?v=surface-1

- Unity 6000.3.1f1, WebXR Export / Interactions 0.25.0, исходная модель sunny_kitty.glb с текстурой.
- В обычном браузере модель видна по центру. В AR включены стабильное пространство local и WebXR Hit Test.
- На горизонтальной поверхности появляется бирюзовый круг. XR select (касание экрана) размещает котика в отмеченном месте. Основание модели находится на поверхности; она остаётся на месте при движении камеры.
- Повторное касание переносит ту же модель на новую найденную поверхность. При потере hit-test нельзя разместить модель; уже поставленный котик сохраняется. Новый вход в AR сбрасывает размещение.
- Unity: 11 проверок размещения на синтетических XR-позах прошли. Node.js: 4 проверки сессии и событий select прошли. Это проверки логики, физическое размещение пока не подтверждено на телефоне.
- WebGL: compression Disabled, decompression fallback OFF, threads OFF. Ошибки сборки: 0, предупреждения: 0.
- Размер файлов Build: **38292336 байт (36.52 МиБ)**; WASM: 31577763 байт. Имена файлов содержат хеши для обновления кэша. Это размер файлов до возможного транспортного сжатия CDN.
- Локальный HTTPS: цепочка TLS, WASM MIME, XR select bridge и совпадение отданных байтов проверены.
- Обычный браузер: котик с текстурой виден, ошибок/предупреждений консоли нет.
- Нужен Android Chrome с ARCore, Google Play Services for AR и поддержкой WebXR Hit Test. При неподдерживаемой функции или отказе доступа сессия не запускается; страница выводит короткое сообщение.
- Предыдущий мобильный тест подтверждал только viewer-space. Для нового размещения нужен повторный тест; см. MOBILE-TEST.md.

Доказательства: placement-checks.json, unity-build.json, verification.json; опубликованные файлы — pages-verification.json после завершения публикации.
